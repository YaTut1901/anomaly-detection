# Лабораторна робота №3: обробка, очищення та зменшення розмірності даних

## Мета

Ознайомитися з методами **обробки**, **очищення** та **зменшення розмірності** даних у Python: пошук пропусків, робота з аномаліями, **масштабування** та **нормалізація** числових ознак, перетворення дат.

## Підготовка даних

1. Згенеруйте CSV скриптом `generate_threats.py`. За замовчуванням файл **`cyber_threats_dataset.csv`**.

2. Для лабораторних прикладів із **пропусками та дублікатами** увімкніть опційні параметри:

```bash
python generate_threats.py 200 \
  --missing-cell-prob 0.08 \
  --duplicate-ratio 0.08 \
  --random-state 42 \
  --output cyber_threats_dataset.csv
```

- **`--missing-cell-prob P`** (0…1) — для кожної з обраних колонок з імовірністю `P` у випадковий рядок записується **пропуск** (`NaN`); для колонки `Timestamp` імовірність зменшена, щоб не «обнуляти» весь час.
- **`--duplicate-ratio R`** (0…1) — додається приблизно **`R × N`** копій існуючих рядків (повторювані записи).
- **`--random-state`** — відтворюваність «забруднення».

Якщо обидва параметри **0** (за замовчуванням), датасет як раніше без штучних пропусків і без дублікатів.

## Завдання роботи (ноутбук `cyber_threats_preprocessing.ipynb`)

1. Завантажити таблицю в **`pandas.DataFrame`**.
2. Переглянути вибірку **`df.head()`**.
3. Підрахувати пропуски: **`df.isnull().sum()`** по колонках і **відсоток** по таблиці **`df.isnull().mean() * 100`**.
4. За **`df.describe()`** оцінити розподіли та підозрілі значення; додано службові колонки **`has_missing`**, **`missing_count`** для позначення рядків із пропусками.
5. Показати ефект **`df.dropna()`** (видалення рядків із будь-яким пропуском) та **`df.dropna(axis=1)`** з виводом **імен видалених колонок**.
6. **Заповнення пропусків** на копії `df_filled`:
   - для числових колонок — **`mean()`**;
   - для текстових (крім `Timestamp` до парсингу) — **`mode()`**;
   - для **`Packet Size`** — додатково **`interpolate(method="linear")`**, потім **`ffill()` / `bfill()`**.
7. Переглянути **`df.dtypes`**, перетворити **`Timestamp`** на **`pd.to_datetime(..., format="ISO8601", utc=True)`**; додати похідні поля: **рік, місяць, день тижня, день місяця**.
8. **Аномалії** за перцентилями **1% і 99%** (`quantile`) по числових колонках.
9. **Масштабування** колонки розміру пакета в інтервал **(-1, 1)** через **`MinMaxScaler`** → колонка **`Packet Size scaled`**.
10. **Нормалізація Box–Cox** для **`Packet Size`** (лише якщо всі значення **> 0**) → колонка **`Packet Size boxcox`**.
11. **Кодова таблиця** (частоти категорій) для текстової колонки **`Packet`**: **`value_counts()`**.
12. Після кроків 6–7 зберегти проміжний результат у **`processed_dataset.csv`** (копія `df_filled` **до** MinMaxScaler і Box–Cox). Після повного пайплайну зберегти **`cleaned_data.csv`** з усіма колонками, включно з **`Packet Size scaled`** та **`Packet Size boxcox`**.

## Примітки

- **Box–Cox** вимагає **строго додатних** даних; після коректного заповнення **`Packet Size`** умова зазвичя виконується.
- Порядок операцій у методичці спочатку масштабує, потім Box–Cox для тієї ж змінної; у ноутбуку **масштабована** версія зберігається окремо, щоб не втрачати вихідні одиниці до перетворення.
- Для парсингу часу з генератора в pandas 3 рекомендовано **`format="ISO8601"`**, якщо у рядках є дробові секунди.

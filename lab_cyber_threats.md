# Лабораторна робота: генерація синтетичного датасету кіберзагроз

## Мета

Ознайомитися з підходами до **генерації**, **збереження** та подальшого **аналізу** синтетичних даних для кібербезпеки: створення штучних записів, що імітують мережеві події та типи загроз, з подальшим експортом у CSV для обробки в Python (наприклад, за допомогою `pandas`).

## Що робить програма

Скрипт `generate_threats.py` формує таблицю з заданої кількості рядків. Кожен рядок описує умовний «пакет / подію» з випадковими, але узгодженими з правилами полями: протокол, прапорець TCP, тип пакета, ідентифікатори сторін, IP та порти, розмір пакета, тип загрози, часова мітка та країни для IP джерела й призначення.

Дані **синтетичні**: вони призначені для навчання моделей, демонстрацій пайплайнів або тестів, а не для висновків про реальні атаки без додаткової перевірки джерел.

## Вимоги до середовища

- Python 3.10+ (рекомендовано актуальну стабільну версію).
- Пакет **`pandas`** (запис CSV через `DataFrame`).

Рекомендовано віртуальне середовище:

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install pandas
```

Опційно для **реальної** геолокації за IP:

```bash
pip install geoip2
```

і файл бази MaxMind **`GeoLite2-Country.mmdb`** (безкоштовна реєстрація та ліцензія на сайті MaxMind).

## Запуск з командного рядка

```bash
python generate_threats.py <кількість_рядків> [--output ФАЙЛ.csv] [--geoip-country-db ШЛЯХ.mmdb]
```

Приклади:

```bash
python generate_threats.py 100
python generate_threats.py 100 --output threats.csv
python generate_threats.py 500 --output out.csv --geoip-country-db /шлях/до/GeoLite2-Country.mmdb
```

- **`rows`** (обов’язковий позиційний аргумент) — кількість записів; має бути цілим числом **≥ 1**.
- **`--output`** — ім’я CSV-файлу. Якщо не вказано, використовується **`cyber_threats_dataset.csv`**.
- **`--geoip-country-db`** — шлях до MMDB-бази країн MaxMind. Якщо **не** вказано, країна для кожного IP обчислюється **детерміновано** з адреси (навчальний режим, без зовнішніх файлів).

Після успішного виконання у консоль виводиться повідомлення українською про кількість записів і ім’я файлу.

## Структура згенерованого CSV

Колонки (зліва направо):

| Колонка | Опис |
|--------|------|
| `Timestamp` | Час події в **UTC**, формат **ISO 8601**. Для кількох рядків мітки **від старіших до новіших** рівномірно розподілені між `2025-01-01` і `2026-04-21 23:59:59` UTC. Для **одного** рядка — одна випадкова мітка в цьому інтервалі. |
| `Protocol` | `TCP` або `UDP`. |
| `Flag` | Прапорець TCP: `SYN`, `ACK`, `RST`, `FIN` (для навчального датасету не прив’язаний жорстко до типу протоколу). |
| `Packet` | Тип пакета / прикладний протокол прикладного рівня: `HTTP`, `DNS`, `SSH`, `FTP`, `SMTP`, `ICMP`. |
| `Sender ID`, `Receiver ID` | Цілі числа від 1 до 1000 (імітація ідентифікаторів). |
| `Source IP Address`, `Destination IP Address` | Випадкові **публічні** IPv4, що пройшли валідацію (див. нижче). **Адреси джерела й призначення ніколи не збігаються** в одному рядку. |
| `Source Country`, `Destination Country` | Назва країни для відповідного IP: або з **GeoLite2** (якщо передано `--geoip-country-db`), або з **детермінованого** списку назв на основі хешу IP. |
| `Source Port`, `Destination Port` | Цілі від 1 до 65535. |
| `Packet Size` | Розмір пакета в байтах, від 64 до 4096. |
| `Target Variable` | Категорія загрози (розширений перелік: Phishing, DoS, DDoS, SQL Injection, Ransomware, Malware, XSS, CSRF тощо). |

Файл зберігається **без** індексу рядків pandas (`index=False`), щоб перший рядок одразу був заголовком колонок.

## Валідація IPv4

Генератор відкидає адреси, які не підходять для імітації «звичайного» публічного юнікасного трафіку. Перевірка реалізована через модуль **`ipaddress`** і додаткові умови:

- відсікання **multicast**, **loopback**, **link-local**, **unspecified** (`0.0.0.0`);
- відсікання **приватних** та **зарезервованих** діапазонів згідно з класифікацією `IPv4Address.is_private` та `is_reserved`;
- явне виключення діапазону **CGNAT** `100.64.0.0/10`;
- вимога **`is_global`** (глобальний юнікас).

У коді є допоміжна функція **`validate_ipv4_string()`** для перевірки довільного рядка IPv4 (наприклад, після імпорту CSV у власних скриптах аналізу).

## Геолокація: два режими

1. **Без `--geoip-country-db`**  
   Країна обирається з фіксованого списку англомовних назв за **детермінованим** правилом від IP (хеш SHA-256). Це **не** справжня географія, але одна й та сама адреса завжди дає ту саму країну — зручно для відтворюваних прикладів.

2. **З `--geoip-country-db` і встановленим `geoip2`**  
   Використовується локальна база **MaxMind GeoLite2 Country** (файл `.mmdb`). Якщо для конкретної адреси запису в базі немає, застосовується той самий детермінований fallback, щоб скрипт не падав.

## Де в коді що шукати

- **Аргументи CLI та запис CSV** — функція `main()`.
- **Один рядок датасету** — `generate_row(row_index, row_count, country_for_ip)`.
- **Збір таблиці** — `generate_dataset(...)`.
- **Випадкова валідна IPv4** — `random_global_ipv4_str()` та `is_valid_public_unicast_ipv4()`.
- **Геолокація** — `geoip_country_lookup()`, `country_from_ip_deterministic()`.

## Обмеження та зауваження для звіту

- Дані **вигадані**; кореляції між полями спрощені (наприклад, прапорець TCP може з’являтися разом з UDP — це компроміс для навчального набору).
- Реальна геолокація залежить від актуальності та типу бази MaxMind і ліцензійних умов її використання.
- Для науково обґрунтованого розподілу загроз і портів потрібні окремі правила або емпіричні розподіли з реальних логів.

## Короткий висновок

Програма демонструє повний мінімальний цикл: **параметри командного рядка → генерація полів з обмеженнями → валідація IP → (опційно) геолокація → експорт у CSV** для подальшого аналізу засобами Python.

# Лабораторна робота №2: аналіз даних кіберзагроз

## Мета

Ознайомлення з використанням інтелектуальних технологій для аналізу даних кіберзагроз. Використання Python-бібліотек **pandas**, **matplotlib**, **seaborn** для базового аналізу табличних даних, підрахунків, групувань і візуалізації.

## Вхідні дані

Таблиця у форматі **CSV** з синтетичними записами про мережеві події та типи загроз (`synthetic/cyber_threats_dataset.csv`). У ноутбуці `synthetic/cyber_threats_analysis.ipynb` шлях задається змінною `CSV_PATH`.

## Завдання роботи

1. Підготувати середовище: встановити **pandas**, **matplotlib**, **seaborn**.
2. Завантажити CSV у `DataFrame`, переглянути структуру (`info`, `describe`, `head`), зафіксувати кількість рядків.
3. Визначити **кількість загроз за типами** (колонка `Target Variable`) і побудувати **стовпчикову діаграму**.
4. Виконати **групування** подій за **рівнем небезпеки** та **IP-адресою джерела**: оскільки в CSV немає окремого поля «рівень небезпеки», у ноутбуку вводиться допоміжна колонка `Danger Level` (Low / Medium / High) за правилом відображення типу загрози; далі — `groupby` і stacked bar з обмеженням топ IP для читабельності графіка.
5. Дослідити **розподіл за протоколами** (`Protocol`) та візуалізувати взаємозв’язок із IP джерела.
6. Проаналізувати **розмір пакета** (`Packet Size`): описова статистика, гістограма розподілу, діаграма для найчастіших значень.
7. У **самостійній частині** (комірки ноутбука): класифікація IP на приватні/публічні, поділ подій на internal/external за обраним правилом, аналіз активності за **годинами доби** з колонки `Timestamp`, горизонтальна діаграма топ **країн** (`Source Country`), пошук IP з високою частотою подій або з великою кількістю різних типів загроз.

## Хід роботи (де реалізовано)

Усі кроки основної та самостійної частини зібрані в одному файлі **`synthetic/cyber_threats_analysis.ipynb`**: послідовні **code cells** — імпорт, читання даних, розрахунки та `plt.show()` / графіки seaborn.

## Технічні примітки

- Для перетворення часу в pandas 3 рекомендовано:  
  `pd.to_datetime(df["Timestamp"], utc=True, format="ISO8601")`,  
  щоб коректно обробляти ISO-рядки з дробовими секундами.
- Розділення **приватна / публічна** IP у ноутбуку: стандартний модуль **`ipaddress`** і атрибут **`is_private`**.
